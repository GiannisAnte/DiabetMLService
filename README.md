# Ml Service

## Запуск проекта

Для запуска необходимо проверить запущен ли Docker, переименовать .env_example в .env, добавить свои переменные окружения в .env,   далее в терминале выполнить команду **docker-compose up --build** .

Web-версия приложения доступна по адресу http://127.0.0.1:8501

Документация Swagger доустпна по адресу http://127.0.0.1/docs

## Описание проекта

Проект представляет собой небольшой сервис для мониторинга диабета. Пользователю необходимо ввести несколько параметров (таких как артериальное давление, уровень глюкозы, вес,возраст и т.п.) и выполнить запрос к модели. Модель проанализирует введенные данные и сообщит о наличии признаков диабета или его отсутствии.

Сервис включает в себя функции регистрации, аутентификации и авторизации пользователей. В личном кабинете доступны следующие функции:
- Просмотр баланса.
- История транзакций пользователя.
- История запросов к модели (включая последний сделанный запрос).
- Функция запроса к модели.

Администратор имеет доступ к отдельному кабинету с функциями:
- Получение списка всех пользователей.
- Просмотр всех транзакций и запросов к модели.
- Редактирование баланса пользователя по ID.
